# FIFA World Cup 2026 Analytics Project

This project analyses FIFA World Cup 2026 team and player statistics using Python.

## Project Tasks 

### Task 1: Possession and Shot Accuracy
This task investigates whether higher-possession teams have better shot accuracy than lower-possession teams.

Statistical methods used:
- Descriptive statistics
- 95% confidence interval
- Shapiro-Wilk normality test
- Levene's test
- Welch two-sample t-test

### Task 2: xG Efficiency
This task tests whether the average xG efficiency of World Cup teams is significantly different from the neutral benchmark of 1.00.

Statistical methods used:
- Descriptive statistics
- 95% confidence interval
- Shapiro-Wilk normality test
- One-sample t-test

### Task 3: Passing Accuracy by Position
This task compares passing accuracy between high-volume defenders and midfielders.

Statistical methods used:
- Descriptive statistics
- 95% confidence interval
- Shapiro-Wilk normality test
- Levene's test
- Welch two-sample t-test

## Files

- `task1.py` – possession and shot accuracy analysis
- `task2.py` – xG efficiency analysis
- `task3.py` – passing accuracy analysis
